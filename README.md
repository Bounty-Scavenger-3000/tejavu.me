# tejavu.me

Personal portfolio site at [tejavu.me](https://tejavu.me).

## Pages

- **`/`** — working resume: Education, Work Experience, Projects, Activities, Certifications, Skills
- **`/secret`** — interactive retro desk scene with panels for Projects, Skills, Audit Report, About, Contact, The Board, Timeline, Gallery
- **`/logo`** — logo export page (5 colour variants, PNG download)

## Stack

Vanilla HTML/CSS/JS. No build step, no framework. Each page is a single self-contained file. Hosted on GitHub Pages.

## Branches

| Branch | Purpose |
|---|---|
| `main` | Production — what's live at tejavu.me |
| `dev` | Working copy — merge into main to deploy |

Work on `dev`, merge into `main` when ready to push live.

## Docs
